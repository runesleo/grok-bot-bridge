You hand your Grok Bot a task with a job id. That id is sent once, and a repeat is blocked. When the bot finishes, the first line is BRIDGE_RESULT plus the id, and the agent that sent the task pulls the answer back with one command.

Bridge Bot, by Moritz, sends the task out. This one also blocks a duplicate send and brings the result back. The code is on GitHub under MIT.

In Claude Code: /send-to-grok-bot and /grok-bot-results.
